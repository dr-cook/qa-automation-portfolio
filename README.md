### ✅ Modules

#### 01 — Cucumber + Selenium (Java)
BDD-style E2E tests using Page Object Model pattern.
- Login flows, form validation, navigation
- Feature files written in Gherkin
- Structured with step definitions and page objects

#### 02 — Playwright (TypeScript)
Modern E2E automation running on Chromium, Firefox and WebKit.
- Login flow: valid credentials, invalid password, invalid username
- Cross-browser execution out of the box
- 9/9 tests passing across 3 browsers

#### 03 — API Testing (Python)
REST API validation using pytest and requests.
- Positive and negative test scenarios
- JSON schema validation
- Status code and response body assertions

#### 04 — Data Quality (SQL + Python)
Database-level validation scripts.
- Oracle and PostgreSQL queries
- pandas-based data integrity checks
- Jupyter notebooks for exploratory analysis

#### 05 — CI/CD (GitHub Actions)
Automated pipelines triggered on every push.
- Playwright tests run on pull requests
- HTML reports published as artifacts
